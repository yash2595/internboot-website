# InternBoot Website

Official website repository for **InternBoot** - Online internships with certification for students and freshers in Web Development, Data Science, Cyber Security, Digital Marketing, and more.

## Features & Pages
- Home (`index.html`)
- Internship programs & details (`internship.html`, `internships/`)
- Student registration & verification (`register.html`)
- Achievements & testimonials (`achievements.html`, `pastlearner.html`)
- Ambassador program & terms
- Privacy Policy, Refund Policy & Terms of Service

## Tech Stack
- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap / Font Awesome
